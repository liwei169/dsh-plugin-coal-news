# 煤矿资讯（DSH 插件）

在 DeepSeek Harness 左下角常驻一块「**腾盛推荐**」信息板：分类查看煤矿行业的科技、安全、价格与政策动态，每 30 秒刷新，并实时显示焦煤、焦炭主连价格。

---

## 功能

| 能力 | 说明 |
| --- | --- |
| 分类信息流 | 全部 / 科技 / 安全 / 价格 / 政策 / 综合六个标签，切换即筛，不额外请求 |
| 30 秒刷新 | 面板展开且页面可见时每 30 秒取一次快照；折叠或切到后台自动暂停，恢复时立即补一次 |
| 手动刷新 | 面板右上角 ⟳，立即触发 Host 侧全源刷新 |
| 价格条 | 焦煤主连（JM0）、焦炭主连（J0），含现价与涨跌幅（红涨绿跌） |
| 秒开 | 上次快照存在浏览器 `localStorage`，打开面板先渲染旧数据再后台刷新 |
| 降级 | 单个来源失败不影响其余来源，页脚标注「N 个来源不可用」并可悬停查看原因 |
| 折叠 | 收起到只剩标题栏，折叠状态下停止轮询，也仍可拖动 |
| 关闭 | 标题栏 × 号关闭，面板直接消失、不留任何入口；本次 Harness 会话内不再出现（刷新页面也不回来），重新打开 Harness 后恢复 |
| 拖动 | 按住标题栏拖到任意位置；位置记住，窗口缩放会自动夹回可视区；双击标题复位。拖到屏幕下半部分时改为底部锚定，展开时向上生长，不会溢出屏幕 |

点标题在浏览器新标签页打开原文；本插件只保存标题、来源与链接，不转载正文。

## 数据来源

| 类型 | 来源 | 抓取方式 | 刷新频率 | 时效窗口 |
| --- | --- | --- | --- |
| 安全 / 政策 | 国家矿山安全监察局（要闻、通知公告） | 列表页 HTML 解析，各翻 2 页 | 10–15 分钟 | 60 / 90 天 |
| 政策 | 国家能源局 | 首页列表解析，按煤炭关键词过滤 | 15 分钟 | 60 天 |
| 行业资讯 | 中国煤炭报（首页、要闻、市场、热点、企业、专题六个栏目） | 列表页 HTML 解析，各栏目翻 3 页 | 10–20 分钟 | 60 天 |
| 行业资讯 | 中国电力新闻网 | 列表解析，按煤炭关键词过滤 | 15 分钟 | 60 天 |
| 地方政策 | 山西省能源局、内蒙古自治区能源局 | 列表页 HTML 解析 | 30 分钟 | 90 天 |
| 陕西 · 官方 | 陕西省政府（新闻 + 公示公告）、陕西省应急管理厅（要闻 + 通知公告 + 公告公示）、陕西省发改委·公告公示、陕西省能源局 | 列表页 HTML 解析，按煤炭关键词过滤 | 30 分钟 | 90–180 天 |
| 陕西 · 企业 | 陕煤集团官网 | 列表解析，按煤矿关键词过滤 | 15 分钟 | 90 天 |
| 价格 · 指数 | 中国煤炭市场网（CCTD） | 列表解析，只取带日期的文章 | 30 分钟 | 180 天 |
| 官方 · 省局 | 国家矿山安全监察局宁夏局、湖北局 | 列表页 HTML 解析 | 15 分钟 | 90 天 |
| 官方 · 部委 | 应急管理部·地方应急 | 列表页 HTML 解析，按煤炭关键词过滤 | 30 分钟 | 180 天 |
| 价格 | 新浪财经国内期货接口（`nf_JM0`、`nf_J0`、`nf_ZC0`） | JSON/文本接口，GBK 解码 | 45 秒 | — |

- 所有请求由本机 Host 的 `fetch` 发出，沿用 DSH 的代理设置，浏览器不直接访问外部站点（也避开了 CORS 限制）。
- 翻页只翻已确认存在的页数（中国煤炭报 3 页、矿山安监局 2 页），页面 500 或改版时自动跳过，不影响同源其他页。
- 有些站把日期印在链接旁边的单元格里而不写进 URL（陕煤集团、CCTD），解析器会读取链接前后 160–260 字符内最近的日期；这类源同时要求"必须有日期"，宁缺毋滥。
- 无日期的条目排在所有带日期条目之后，不会挤占列表顶部。
- 实测口径：24 个来源、200 条（面板上限），9 月 14 / 10 月 64 / 11 月 122；分类分布 综合 68 / 价格 45 / 安全 41 / 政策 34 / 科技 12。分类只影响筛选，「全部」里所有煤矿相关稿件都会出现。
- 仅抓取公开页面、限频并带浏览器 UA；页面结构变更会导致单个来源失效，面板会显示出来而不是静默失败。
- 动力煤（ZC）当前无有效行情，自动隐藏该合约。

## 安装

DSH → **插件** → **添加插件** → 填 `dsh-plugin-coal-news` → 安装。

安装后刷新 DSH 页面，左下角出现「腾盛推荐」面板。

> 需要包含 `ctx.connection.rpc` 与 `shell.overlay` 的 DSH 版本；本插件在 2026-11 的桌面版上开发。

## 工作原理

```
Host（Node）                                    浏览器
├─ 每源独立定时器（带 jitter）                     ├─ 面板挂载 shell.overlay
├─ fetch → 解析 → 分类 → 去重 → 内存缓存          ├─ 每 30 秒 rpc.call('/coal-news','feed')
└─ ctx.connection.rpc.handle('/coal-news')  ←──→  └─ localStorage 快照 + 五态渲染
```

- RPC 通道：`/coal-news`，接口 `feed`、`quotes`、`status`、`refresh`（全部只读，`refresh` 仅触发后台刷新）。
- 缓存按 URL 的 sha1 去重，最多保留 1200 条，按发布时间倒序；无日期条目回退为抓取时间。
- 分类先按标题规则判定（事故类优先，其次是文件类，再次是执法、价格、科技），无命中时用来源的默认分类。

## 配置

当前版本没有配置文件。可调项在两处：

- 源表、分类默认值与刷新间隔：`src/sources.js`
- 用户偏好（折叠状态、上次快照）：浏览器 `localStorage`，键名 `dsh.coal-news.*`

## 开发

```powershell
node --check index.js
node --check client.js
npm test          # 30 个离线单测：解析、分类、缓存、行情、时效窗口、面板渲染
npm run self      # 联网自检：真实抓取全部资讯源 + 行情，打印分类分布
node scripts/report.mjs   # 更细的报告：按来源/月份统计、最新 10 条、每个来源的错误
```

`npm run self` 会访问外网，需要能连通上述站点。

需求与设计文档见 [`docs/REQUIREMENTS.md`](docs/REQUIREMENTS.md)。

## 已知限制

- 资讯发布时间来自 URL 中的日期，粒度到天；`国家能源局` 与 `中国煤炭报` 只取首页/栏目首屏。
- 每个来源只保留最近 30 天（通知公告 45 天）的条目，更早的内容不会进入面板，避免案例库和旧文件混进新闻流。
- 中国煤炭市场网（CCTD 指数）尚未接入：站点结构较重且存在反爬，价格目前只有期货。
- 面板是可拖动的浮层（默认左下角，双击标题复位），但不支持停靠到侧边栏；右侧边栏形态尚未实现。
- 国家矿山安全监察局陕西局官网（`shaanxi.chinamine-safety.gov.cn`）对非浏览器指纹返回 412，暂未接入；陕西内容由省政府、省应急管理厅、省能源局三个来源覆盖。
- 未实现收藏、搜索、AI 摘要与 Agent 工具 `coal_news`（见需求文档 P2 列表）。
